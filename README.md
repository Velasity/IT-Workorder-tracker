# ⚡ IT Workorder & Ticketing Portal
> A streamlined, enterprise-ready IT management platform designed for Managed Service Providers (MSPs), corporate IT teams, and after-hours emergency support operations.

### 🚀 Built For Speed & Simplicity
Built as a modern alternative to bloated enterprise tracking systems, this platform delivers high-performance workorder management, multi-role access control, and dedicated after-hours handling without the heavy infrastructure overhead.

### 🛠️ Core Tech Stack
* **Backend:** Node.js, Express
* **Database:** SQLite (Lightweight & Portable)
* **Frontend:** Clean, responsive HTML/CSS/JS interface
* **Architecture:** Designed for local deployment, easy extension, and future native packaging (Electron).
